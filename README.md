# JonHarmonic
Free long-form music by JonHarmonic (Resonix Records). Live: https://john432hz.github.io/jonharmonic/

Audio is served from the repos jonharmonic-audio-1, -2 and -3 (GitHub Pages); all 117 MP3s are also attached to the release `v1.0-audio`. Generated from the app by tools/build-pages.py.
